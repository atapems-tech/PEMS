## Evidence

Owner requirement 2026-10-18: GitHub Actions checks whether the host is reachable and deploys; otherwise it reports that it is not reachable and the created artifact is uploaded so it can be deployed manually. A host may be unreachable from GitHub, for example because of its location.

## Prompt

Add to the shared deploy workflow (HST_ACTIONS) a pre-flight reachability check of the deploy channel. If reachable, deploy automatically. If not, publish the built artifact (workflow artifact or release) with its checksum and a manual-deploy guide, notify the owners (email or GitHub issue) and mark the run 'manual deployment needed'. Provide a self-contained manual deploy script that performs the same steps as the pipeline (verify checksum, back up, switch release, migrate, health check, roll back on failure) so manual and automatic deploys are identical. Applies to both the landing and the demo pipelines.

## Requirement

With the host unreachable, a run ends with a downloadable, checksum-verified artifact and a notification, and running the manual script on the host gives the same result as an automatic deploy; with the host reachable no manual step is needed.
