## Evidence

The customer must be able to start and finish the recovery from the product UI of their own installation, and the product must accept only an answer to its own request. Gate: this row can start only after #342 (licence flow end to end) is Done. Independent of the separate administrator-recovery work done by Saber (second-admin reset, one-time recovery codes, server-side break-glass, shared audit/notification/session revocation): that work does not wait for the licence flow and this row does not block it; this flow plugs into it as the optional vendor-assisted recovery path, which must stay off until the customer enables it.

## Prompt

Add the recovery page (anonymous-safe, on the always-free surfaces list) with a setting that keeps it disabled until a customer administrator enables it. Generate the .pemsrstreq (#344) and store the pending request (nonce, time, requested account) through an EF migration. On upload of a .pemsreset verify signature and expiry, match the stored nonce, licence id, Install ID and fingerprint hash against the installed licence (#98, #99), consume the pending request, then open the form to set a new administrator password under the password policy, require a change at next sign-in, handle MFA/passkeys and revoke the account's sessions (#182) as decided in #343, write the audit, notify all administrators, send the event to the SIEM feed and rate-limit failures. Reject a response whose validity is outside 1 to 7 days or whose expiry has passed (use the clock guard #105), and expire the pending request on the same bounds.

## Requirement

Done when: a valid response file resets the administrator password once on the matching installation; the same file again, an expired file, a file for another installation or request, and a tampered file are refused with an audit entry; sessions end; with the setting off the page offers nothing. A response valid for more than 7 days is refused even when correctly signed.
