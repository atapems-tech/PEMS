## Evidence

PM review 2026-10-18: make a branch policy for each release. V_BRANCH sets the overall strategy; each release line needs its own explicit rules so a customer's version can always be reproduced and patched.

## Prompt

For each release create release/<version> from main at the release candidate; allow only fixes and documentation on it; require review and the CI workflow to pass; backport every fix to every supported release branch; protect the branch from force-push; record creation, supported period and retirement date in the release map (CV_MAP); no per-customer branches.

## Requirement

Every shipped version maps to one protected release branch and one tag; the release map lists each branch with its support period; a hotfix reaches all supported branches by backport.
