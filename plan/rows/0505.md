## Evidence

Owner request 2026-11-05: the naming of files, functions and fields should get better. Audit of the code on 2026-11-05: the folder PEMS.Persistence/Servises (a typo of Services) holds 248 files; view-model-like types end in Dto (423), Model (50), ViewModel (36) and Vm (12) with no rule; entity names start with unexplained abbreviations (AI, VDR, MDR, ITP, MDB, PM, QC, IO); 10 of 111 controllers are plural, the rest singular.
