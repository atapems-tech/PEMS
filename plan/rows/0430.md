## Evidence

Plan audit 2026-10-28: docs/audits/2026-10-28-dynamic-restful-audit.md. The backlog designs forms (#44), views (#57), dashboards (#58), reports (#59), menus (#20) and workflows (#67) one by one, each with its own storage idea, and nothing defines a page or a component instance. 'All pages, components and forms creatable and editable from the UI' needs one shared definition model first.

## Prompt

1) List the definition kinds and their relations (Page, Layout, Region, ComponentInstance, DataSource, Action, Form, View, Dashboard, Report, Menu, Theme). 2) One envelope and one version/publish/rollback rule for all of them, reusing the registry (#338). 3) Component instance = component key + options JSON that validates against the component manifest (#433). 4) Static-to-dynamic coexistence: a database definition may override or extend a code default; rollback = delete the override. 5) Cache, invalidation, size limits, security (who can publish). 6) Write plan/adr/NNNN and update the registry design.

## Requirement

Done when: the ADR is accepted (storage, envelope, draft/publish/rollback, how a static page and a database page coexist, cache and invalidation, size and security limits); rows #338, #387, #44, #57 and #20 reference it; open questions have an owner.
