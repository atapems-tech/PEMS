## Evidence

One shared, tested implementation prevents the owner UI and the product from disagreeing about what a valid file is. Gate: this row can start only after #342 (licence flow end to end) is Done. Independent of the separate administrator-recovery work done by Saber (second-admin reset, one-time recovery codes, server-side break-glass, shared audit/notification/session revocation): that work does not wait for the licence flow and this row does not block it; this flow plugs into it as the optional vendor-assisted recovery path, which must stay off until the customer enables it.

## Prompt

Implement the two formats from the ADR (#343) in a shared library: canonical encoding; request signed by the install key; response signed by the reset key with domain separation from licence files; response bound to the request nonce, licence id, Install ID, fingerprint hash, reset key id, issued-at, expires-at and purpose. Unit tests with vectors for valid, expired, tampered, wrong-nonce, wrong-installation, wrong-key and wrong-purpose files, each rejected with a distinct reason. The response carries issued-at and expires-at; the library enforces 1 to 7 whole days between them, with the limits as shared named settings used by both sides; add vectors for a validity of 0, 8 days, negative and missing.

## Requirement

Done when: the library creates and verifies both files; every negative vector is rejected with its own reason; the owner UI (#345) and the product (#346) use the same code. Validity outside 1 to 7 days is rejected.
