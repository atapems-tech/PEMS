## Evidence

The owner needs a safe, offline place to answer a customer's reset request without exposing the licence signing key. Gate: this row can start only after #342 (licence flow end to end) is Done. Independent of the separate administrator-recovery work done by Saber (second-admin reset, one-time recovery codes, server-side break-glass, shared audit/notification/session revocation): that work does not wait for the licence flow and this row does not block it; this flow plugs into it as the optional vendor-assisted recovery path, which must stay off until the customer enables it.

## Prompt

Add a Reset admin page to the vendor tool (#106), run on an owner computer (Hamid's or Saber's own computer, where the reset key lives): upload the .pemsrstreq, verify its signature, find the matching licence in the ledger (#341) by licence id, Install ID and fingerprint hash, show the customer and let the owner confirm or pick the customer (a mismatch is a warning that blocks issuing), enter the reason and the identity check performed, choose the validity in whole days (default 1, range 1 to 7, no unlimited option), then download the .pemsreset built with #344 and signed with the reset key (#349). Revoked or expired licences cannot be answered. Write an audit entry (who, when, customer, licence, request nonce, expiry, reason). Works fully offline. All in the UI; no terminal or CLI step.

## Requirement

Done when: from an uploaded request file the owner issues a response file for the right customer in under a minute with no network; a request for a revoked licence or for an unknown installation is refused; the audit shows each issue. A validity outside 1 to 7 days cannot be chosen.
