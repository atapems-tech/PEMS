## Evidence

A per-machine TLS certificate generated at first run, with no shipped private key (fail-closed), is a proven approach. 2026-10-27: the administrator step is #381 (the administrator chooses the password as the last install step, guarded by a one-time setup code); this row keeps the wizard frame, licence, TLS and MFA steps.

## Prompt

A browser step wizard: licence, machine TLS certificate, admin with a strong password and MFA, minimal seed. Everything in this flow is done in the UI; no terminal or CLI step is required (a CLI may exist only as an optional extra).

## Requirement

A fresh install without a terminal reaches a system locked to the licence and TLS.
