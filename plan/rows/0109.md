## Evidence

Known failure modes: the setup token was not created when only the licence was missing, and a DB-bound rate limiter made the request hang.

## Prompt

First run in the browser: a licence page, then create the admin, then prepare the DB; the first-run pages are reachable only from the server itself or with a one-time token shown by the graphical installer (never by reading a console log); in-memory rate limiting. Everything in this flow is done in the UI; no terminal or CLI step is required (a CLI may exist only as an optional extra).

## Requirement

A fresh install without a ready DB shows the licence page with no hang and every first-run step is a UI page.
