## Evidence

Owner requirement 2026-10-18: automated deployment needs access to the host; that access must not let one pipeline touch the other site.

## Prompt

Create a deploy account for landing and another for demo (and per environment), each allowed to write only its own release directory and restart only its own service; keys stored as environment secrets and rotated.

## Requirement

The landing deploy account cannot read or write the demo and vice versa; a leaked key reaches only one site and one environment.
