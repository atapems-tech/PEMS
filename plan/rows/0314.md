## Evidence

Owner request 2026-10-23. Today the login page has no release information and the repository only has a developer CHANGELOG.md. Customers installing or updating (#309/#310, #167) cannot see what changed. The login page is the one surface every user sees; the brand profile already comes from the database for the same page (see Lessons: live brand profile).

## Prompt

Design first: one source of truth for release notes (a curated, bilingual 'release notes' data file or table maintained per release - NOT the raw developer CHANGELOG), shipped inside the package and loaded from the database/disk with no external call. Then add a compact panel to the login page: latest release title and date, 3-5 highlights, 'older releases' expander, anonymous-safe (no internal ids, user names or unreleased work). Entries are written in the release task; the pipeline fails the release if the notes for the tagged version are missing.

## Requirement

The login page shows the notes of the installed release in the active language without any internet access; only features that are Done with evidence are listed (Instructions rule 13); the panel works for an anonymous visitor, is accessible (keyboard, contrast, RTL) and collapses on small screens.
