## Evidence

With independently versioned modules a customer could end up with a module that does not run on their core, or the reverse.

## Prompt

Evaluate declared compatibility ranges at install and update time and compute, per customer, the valid next core and module versions.

## Requirement

An incompatible combination is refused with a clear message; the registry shows the valid combinations for each customer.
