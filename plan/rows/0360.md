## Evidence

Import Center has 11 imports with their own checks. A blank cell in an update row must leave the value alone, a malformed identifier must never reach the database as a server error, and a default value must never be saved as NULL by a bulk path. 2026-10-28 plan audit: dependency/milestone corrected (see docs/audits/2026-10-28-dynamic-restful-audit.md).

## Prompt

1) The import designer (#25) and the Import Center call the validator of #356 per row. 2) Row-level error report (row, column, message, value) and a preview before commit. 3) Update mode: a blank cell leaves the stored value unchanged and 'required' applies only to columns present in the file. 4) Omitted columns with a default get the default (links to #26). 5) Reject malformed GUIDs and numeric keys as validation errors. 6) Limits for file size, rows and columns as settings (OWASP: cap sizes before parsing). 7) Persian digits and Jalali dates normalised (#364). 8) Test with 50,000 rows and mixed errors.

## Requirement

Done when: a 50,000-row file with errors produces a complete row-level report and commits nothing, or only the valid rows if the user chooses; partial updates never clear data; a malformed identifier gives a message, not a server error.
