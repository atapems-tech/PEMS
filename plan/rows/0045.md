## Evidence

The heart of dynamism; one set of components for create/edit/view/print.

## Prompt

Render from form JSON, validate on client and server, store the form version on the record. Update 2026-10-28 (#460): the runtime computes the editable field set for the current state and user, passes it to the validator and to the client script, shows non-editable fields read-only without validation errors, and stores the form version on the record so a record keeps the rules it was created under until a step edits the field.

## Requirement

Changing a published form does not corrupt older records (versioned).
