## Evidence

Without a manifest nobody can tell which source and which archived package a deployed version came from.

## Prompt

Define the manifest schema for the core package and for each module package, generate it in CI, sign it and embed it in the package; the app and the updater read it.

## Requirement

From a package or an installed system you can read its tag, commit and build number and find the archived artifacts.
