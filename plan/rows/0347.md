## Evidence

A recovery path is a favourite attack target; it must be covered by tests before it ships. Gate: this row can start only after #342 (licence flow end to end) is Done. Independent of the separate administrator-recovery work done by Saber (second-admin reset, one-time recovery codes, server-side break-glass, shared audit/notification/session revocation): that work does not wait for the licence flow and this row does not block it; this flow plugs into it as the optional vendor-assisted recovery path, which must stay off until the customer enables it.

## Prompt

Write integration tests against the real product endpoint and the owner UI library: replay of a used response, expired response, response for another request or installation, modified payload, signature by a different or revoked key, forged request file, cloned machine (fingerprint mismatch), clock rolled back, repeated failures reaching the rate limit, the feature switched off, and that sessions, MFA state, audit and administrator notifications are as specified. Add them to the CI gate. Include validity 0, 8 days and a missing expiry, and a response used exactly at and just after its expiry.
