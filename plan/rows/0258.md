## Evidence

There is no written branching or release-line policy, and no way to tell later which source produced a given installer.

## Prompt

Define: main for integration, release/YYYY.MM branches for supported lines, signed annotated tags vYYYY.MM.PATCH, hotfix branches with backport to every supported line, commit messages that cite the backlog row number, and no per-customer branches. Also define the one allowed long-lived non-release branch, demo (HST_DEMOBRANCH), which carries only the demo overlay.

## Requirement

A written policy; every shipped package maps to exactly one signed tag and commit.
