## Evidence

Plan audit 2026-10-28: docs/audits/2026-10-28-dynamic-restful-audit.md. A page made of components is useless until the components can be wired to data and behaviour without code.

## Prompt

Define DataSource (kind, entity/view/endpoint, parameters, paging, filters) and Action (kind, target, confirmation, permission) definitions per #430; resolve them on the server through the REST API (#431/#12) with RLS; component options reference them by key; use the PemsEmptyState/ErrorState/LoadingState for the three result states.

## Requirement

Done when: a list component and a button on a database page load data and trigger a workflow action using only stored definitions; a user without permission sees neither the data nor the action; the binding model is validated against the manifests (#433).
