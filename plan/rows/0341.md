## Evidence

Today there is no record that lets the owner pick a customer and find the licence that customer received. Licences issued before the ledger existed must stay usable for later owner actions such as the one-time admin reset (#343-#349). The separate administrator-recovery work done by Saber (second-admin reset, recovery codes, server-side break-glass) does not depend on this row and can proceed without it.

## Prompt

In the vendor tool (#106) keep a ledger: customer, licence id, Install ID, fingerprint hash, signing key id, edition/modules, type and period, status (active/revoked/expired), issue date and the original request nonce. Add an import action: upload an already issued .pemslic (or zip); the tool verifies the signature with the public key, reads the bound fields and creates or updates the ledger row after the owner confirms the customer. Everything is done in the UI; no terminal or CLI step is required. Every change writes an audit entry. Export to CSV/Excel.

## Requirement

Done when: the owner selects a customer in the vendor tool and sees every licence issued to it; a licence file issued before the ledger existed is imported with a valid signature and appears in the list; a tampered file is rejected; each import and edit is audited.
