## Evidence

Options: (a) real SQL tables via guided DDL, (b) JSON column plus indexed computed columns, (c) EAV. PEMS runs on EF Core 10 + SQL Server.

## Prompt

Benchmark all three with a small prototype (100k records, filter/sort/report). Initial recommendation: hybrid, with real tables for fully user-defined entities and a JSON column for custom fields on existing static entities.

## Requirement

An approved ADR with performance criteria, migration cost, reporting impact and effect on RLS and audit.

## Report

Decided 2026-10-18: hybrid - real SQL tables for fully user-built entities, one JSON column for custom fields on existing entities. Prototype validation happens in D_DDL/D_SCHEMA; ADR to be written under F_ADR.
