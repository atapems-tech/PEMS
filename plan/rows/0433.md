## Evidence

Plan audit 2026-10-28: docs/audits/2026-10-28-dynamic-restful-audit.md. Options are now named-property records with required/optional members (SCRUM-424), so a schema can be generated rather than written. A designer cannot offer 'add a component to a page' without knowing each component's inputs.

## Prompt

Generate JSON Schema (System.Text.Json schema exporter or NJsonSchema, licence recorded) from the options types; add [PemsComponent] metadata (category, icon key, TranslatableText name/description); expose through the definition store (#434) and the catalog (#326); add the completeness test.

## Requirement

Done when: a generator produces one JSON manifest per component from the code (no hand-written schema); a stored options JSON that violates the schema is rejected with a field error list; the manifest of Button, Badge, Field, Table, Form, Empty/Error/Loading state exists and a test fails when a component has no manifest.

## Report

Done in the PR of branch feature/SCRUM-433-component-manifest-hamid: [PemsComponent] now carries Category and Icon and is on all nine registered components (button, badge, skeleton, field, table, form, empty-state, error-state, loading-state); ComponentManifestGenerator builds one manifest per component from the code with the built-in JsonSchemaExporter (TranslatableText as string or language map, unknown properties rejected, required from C# required/EditorRequired); ComponentManifestCatalog validates stored options JSON with LateApexEarlySpeed.Json.Schema (BSD-3-Clause) and returns a field error list (JSON Pointer, constraint code, message key) and converts valid options to component parameters; approved snapshots in PEMS.UI.Tests/Manifests.
