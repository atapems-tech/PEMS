## Evidence

Public key in the app, private key only at the vendor (Ed25519 offline licensing is proven).

## Prompt

Fields: customer, Install ID, fingerprint hash, edition, modules/features, limits (sites and modules; no user limit), type and period, updates-until date (maintenance period, see CV_UPDENT), request nonce, issue counter; support a zip bundle of several licences.

## Requirement

A licence issued for request A is never valid on install B; a tampered signature test is rejected.
