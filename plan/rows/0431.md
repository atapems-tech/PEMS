## Evidence

Plan audit 2026-10-28: docs/audits/2026-10-28-dynamic-restful-audit.md. Today there is no REST surface: 147 controllers, none marked [ApiController], 163 GET and 668 POST actions, no PUT/PATCH/DELETE, no OpenAPI, no ProblemDetails, no API versioning; 22 controller files return ad hoc JSON. Row #12 plans /api/d/{entity} without a standard to follow.

## Prompt

1) Resource naming and URL rules (plural nouns, nested only for ownership, actions as POST sub-resources, e.g. POST /work-orders/{id}/actions/approve). 2) Verbs and status codes (200/201+Location/204/202, 400/401/403/404/409/412/422/428/429). 3) Query contract for paging, sorting, filtering, search, field selection (offset vs cursor decision). 4) Concurrency (ETag/If-Match, 412/428) and idempotency (Idempotency-Key). 5) Errors: RFC 9457 with the field-error list of #363. 6) Versioning and deprecation. 7) i18n: Accept-Language, TranslatableText JSON shape, UTC/ISO dates. 8) Allowed-actions and permission hints for dynamic UIs. 9) Browser auth (cookie plus antiforgery) vs integration auth (token). 10) Write the ADR and the guideline chapter.
