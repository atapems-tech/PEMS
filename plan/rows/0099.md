## Evidence

Owner need: lock to the machine and to the install time. A random Install ID is created on first run and sealed with a local key (DPAPI/TPM where available); the licence binds to this ID and the fingerprint.

## Prompt

Generate an install key pair, store the private key non-exportable (DPAPI machine scope or TPM), write the seal in two independent places (DB + file) and verify consistency on every start.

## Requirement

Copying a disk/image to other hardware cannot open the seal (machine-bound key) and the app drops to 'activation required'.
