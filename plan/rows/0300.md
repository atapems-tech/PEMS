## Evidence

Owner requirement 2026-10-18: the demo is a branch of the main repository, while the landing website is a separate repository. Without rules the demo branch drifts from main and becomes a fork.

## Prompt

Create the demo branch from main with a clearly separated overlay directory (demo data pack, reset scripts, deploy workflow, demo configuration). Sync main into demo automatically (a scheduled workflow that merges or opens a pull request, never demo into main). Commit product changes only on main; implement demo-only behaviors as demo-mode configuration flags in the product (see DM_PERSONA, DM_SAFE), not as code edits on the demo branch. Protect the branch and limit who can push.

## Requirement

The demo branch differs from main only by the overlay directory; a sync from main runs automatically and reports conflicts; a check fails any change on demo outside the overlay; no commit from demo is ever merged into main.
