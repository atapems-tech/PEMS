## Evidence

The product never phones home, so the registry needs a file-based way to learn what is actually installed.

## Prompt

A 'Generate version report' action in the admin UI producing a signed file; an import function in the vendor registry UI that updates the deployment record and flags drift. Everything in this flow is done in the UI; no terminal or CLI step is required (a CLI may exist only as an optional extra).

## Requirement

Importing a report updates the customer's installed version and update history; a tampered report is rejected.
