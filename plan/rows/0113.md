## Evidence

PM review 2026-10-18 (licensing chain, cluster C): made simpler. The first version only switches whole modules on and off from the licence; finer feature rules are a separate Hold row (L_ENTITLE_ADV).

## Prompt

Read the enabled modules from the signed licence; hide disabled modules from the menu (D_MENU) and deny their API calls on the server. One check function, used everywhere.

## Requirement

A module that is not in the licence is neither in the menu nor reachable through the API; enabling it needs only a new licence.
