## Evidence

The current UI is Razor + Bootstrap + jQuery with 225 views and page-specific JS/CSS (pems-data-grid.js etc.). Options: ViewComponent/TagHelper + Web Components, Blazor, or an SPA hosted inside the app.

## Prompt

Compare the three options with a vertical slice (grid + form). Criteria: fully offline without CDN, RTL, form-builder velocity, upgrade path from existing Razor.

## Requirement

An approved ADR; all CMP_* and FRM_* work is defined against it.
