## Evidence

Plan audit 2026-10-28: docs/audits/2026-10-28-dynamic-restful-audit.md. Today 303 pages are hand-written views; this is the runtime that makes a page data.

## Prompt

PageHost controller/view that loads the definition, resolves layout and regions, renders each instance through the component renderer (PEMS.UI) with its manifest-validated options; cache per definition version with invalidation on publish; routing for database pages; visibility rules from the expression engine (#15).

## Requirement

Done when: a page created only in the database renders at its route in fa and en with no deploy; a published change shows on the next request; an unauthorized user gets 403 and a missing page 404; a static page keeps working when its override is removed; render time is within the budget set in #319.
