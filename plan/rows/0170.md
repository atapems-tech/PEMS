## Evidence

A signed update package with an Update page is a proven pattern; PEMS has neither.

## Prompt

An Update page in the admin UI: upload a package, inspect it, apply, view the result and roll back; the package carries version/signature/migration and an automatic backup is taken before applying. Everything in this flow is done in the UI; no terminal or CLI step is required (a CLI may exist only as an optional extra).

## Requirement

An update from 2026.1 to 2026.2 on a sample instance, with rollback, succeeds.
