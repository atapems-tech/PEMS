## Evidence

PM review 2026-10-18: the artifact library is back in scope. There is no archive of shipped installers and updaters; supporting a customer on an old version requires that exact package and its symbols.

## Prompt

An append-only artifact library for core and module packages with a naming scheme (component-version-edition-platform), checksums, signatures, SBOM, debug symbols and the release manifest; offsite copy; retention for as long as a version is supported. It does not depend on a particular build system.

## Requirement

Any package ever shipped can be retrieved byte-identical and verified against its checksum and signature.
