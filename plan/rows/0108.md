## Evidence

Zip upload, show/copy of the fingerprint and automatic restart after a licence upload remove the need for a terminal.

## Prompt

A browser UI for the whole customer licence life: status, fingerprint, generate/download the request file, upload a licence or zip, renewal and transfer requests, emergency licence, expiry warnings. Everything in this flow is done in the UI; no terminal or CLI step is required (a CLI may exist only as an optional extra).

## Requirement

From first run to an active licence the customer completes every step using only the browser UI, without support staff or a terminal.
