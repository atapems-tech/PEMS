## Evidence

A machine-bound licence needs a stable fingerprint. PEMS is .NET only and also ships a Docker option.

## Prompt

Signals: motherboard UUID, CPU id, system disk serial, physical MACs, Windows MachineGuid, /etc/machine-id; weighted with a tolerance threshold (replacing one disk or NIC is allowed, three or more changed signals invalidates the licence).

## Requirement

Test: the same machine after reboot and one NIC replaced stays valid; another machine is invalid; output is hashed (no raw serials exposed).
