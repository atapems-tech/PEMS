Owner goal: lock to machine and install time so that even a full machine image redeployed elsewhere does not work. No offline scheme is unbreakable; the aim is to defeat casual copying and back the rest with the EULA.

## Prompt

List attack scenarios (disk image on other hardware, VM clone, snapshot restore, clock change, binary patch, licence file reuse) and for each record the defense, the residual weakness and the contractual answer.

An approved ADR 'licensing threat model' with a scenario x defense x residual-risk table.
