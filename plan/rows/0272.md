## Evidence

Delivery is not the same as applied. A receipt closes the loop.

## Prompt

The updater writes the receipt and the admin UI offers it for download; the registry import UI marks the package as applied or failed. Everything in this flow is done in the UI; no terminal or CLI step is required (a CLI may exist only as an optional extra).

## Requirement

Every delivered package ends as applied, failed or pending in the registry.
