## Evidence

Owner's process: a file is generated on the customer server, returned to us, then the real licence is issued and delivered. Copying only a fingerprint is not enough; a full request contract is needed.

## Prompt

File contents: hashed fingerprint, Install ID, install time, product version, customer/order id, random nonce, signature by the install key. The customer generates and downloads it from the licence page. Everything in this flow is done in the UI; no terminal or CLI step is required (a CLI may exist only as an optional extra).

## Requirement

Changing one byte of the request file makes the vendor tool reject it; every request has a unique nonce; the customer produces the file entirely in the browser UI.
