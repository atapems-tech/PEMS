## Evidence

Owner requirement 2026-10-27: the texts a component shows (labels, placeholders, help, notes, errors, empty and loading texts) are inputs of the component and later come from the database form tables, one row per form, as JSON that maps a language slug to the text. User-entered data is never translated, only formatted (dates, numbers). Today _PageHeader and _Pagination read PEMS.Web SharedResource, so the library cannot own text.

## Prompt

1) TranslatableText in PEMS.UI.Abstractions: immutable, JSON {"fa":"..","en":".."}, fallback chain (culture, neutral language, default language, language-neutral, first). 2) IPemsLocale: text resolution plus value formatting by culture (Jalali dates for fa, numbers). 3) Descriptors and every PEMS.UI component take TranslatableText inputs and hold no literal text; a test fails when one is added. 4) JSON round trip of FormDefinition and ViewDescriptor. 5) ADR-0008 and the guideline rule. SCRUM-416.

## Requirement

Done when: a FormDefinition loaded from JSON renders in fa and en with no text in the component code; a test fails when a literal text is added to a PEMS.UI component; dates and numbers follow the culture; ADR-0008 is accepted.
