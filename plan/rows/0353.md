## Evidence

Row #141 asks for a nightly and an admin reset but nothing exists; a push to demo or staging updates code and schema only, data is never reset.

## Prompt

Use the package from #352. A baseline package committed to the demo/staging overlay is uploaded by the pipeline; on first start after deploy the app compares the baseline hash with the one recorded in the database, runs the precheck and, if it passes and the environment setting allows it, resets the database to the baseline; otherwise it reports why in the admin UI. Admin UI offers the same reset by upload. Owners and developers only.

## Requirement

Done when: pushing a new baseline to demo (and to staging) resets that environment once; an incompatible baseline leaves data untouched and shows the reason; a manual reset by upload works in the UI; tests cover both paths.
