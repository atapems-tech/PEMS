# 08 Domain model specification: PPC Stage 1 Core (2026-11-16)

**Status:** APPROVED BY OWNER (2026-11-16)  
**Governing decisions:** `Owner-Decisions-2026-11-16.md`, ADR-001 in `06-architecture-decision-proposal.md`.  
**Architecture:** Clean Architecture (`PEMS.Domain/Entities`).

---

## 1. Scope and Design Principles

1. **Non-Breaking & Additive:** Existing execution entities (`ProductionOrder`, `ProductionRun`, `ProductionBatch`, `ProductionLoss`) are augmented strictly via optional/nullable navigation properties. No existing columns are renamed or deleted.
2. **Process First:** Initial manufacturing structures focus on **Process Manufacturing** (formulas, base batch sizes, expected yields, standard loss allowances, and co-products).
3. **Dedicated Routing Entity:** To eliminate semantic overlap with document/storage routing, operation sequences are named **`ProcessRoute`** and **`ProcessRouteOperation`**.
4. **Planning Structure (APP/MPP/MPS):**
   - `ProductionPlan`: Root aggregate for macro and detailed plans.
   - `PlanVersion`: Immutable snapshot representing the owner-approved **MPP** (output of APP).
   - `PlanItem`: Time-bucketed demand and target production quantities.
   - `PlanningRecommendation`: Actionable suggestions generated by the MRP calculation engine (never firm orders until supervisor approval).
5. **Genealogy & QC Gates:**
   - Multi-level relationship between input batches and output batches (`ProductionBatchGenealogy`).
   - Enforced QC validation states (`Released` for input consumption; `AwaitingQC` for initial production output).

## 2. Entity Specifications in `PEMS.Domain.Entities`

### 2.1 Process Product Structure

#### `ProcessFormula` (Aggregate Root)
Represents the approved recipe/formulation for a process product.
- `int ProcessFormulaId` (PK)
- `string FormulaCode` (e.g. "FRM-CHEM-101", unique)
- `string Title`
- `int MaterialItemId` (FK -> `MaterialItem`, the primary product produced)
- `MaterialItem? MaterialItem`
- `int VersionNumber` (Monotonically increasing version, default 1)
- `string Status` ("Draft", "Approved", "Superseded", "Retired")
- `decimal BaseBatchSize` (Reference batch output volume, e.g. 1000.00)
- `int? BaseUomId` (FK -> `MaterialUOM`)
- `MaterialUOM? BaseUom`
- `decimal ExpectedYieldPercent` (e.g. 98.50%)
- `decimal StandardLossPercent` (e.g. 1.50%)
- `string? Description`
- `int? ApprovedById` (FK -> `Employee`)
- `Employee? ApprovedBy`
- `DateTime? ApprovedDate`
- `bool IsActive` (Soft delete flag, default true)
- `byte[]? RowVersion` (Optimistic concurrency token)
- Navigations:
  - `ICollection<ProcessFormulaItem> Items`
  - `ICollection<ProcessFormulaCoProduct> CoProducts`
  - `ICollection<ProcessFormulaOperation> Operations` (ISA-88 Lightweight Operation sequence)
  - `ICollection<ProcessRoute> CompatibleRoutes`

#### `ProcessFormulaItem`
Represents an ingredient or raw material required in the formulation.
- `int ProcessFormulaItemId` (PK)
- `int ProcessFormulaId` (FK -> `ProcessFormula`)
- `ProcessFormula? ProcessFormula`
- `int MaterialItemId` (FK -> `MaterialItem`, ingredient / component)
- `MaterialItem? MaterialItem`
- `decimal QuantityRatio` (Quantity per base batch size)
- `int? UomId` (FK -> `MaterialUOM`)
- `MaterialUOM? Uom`
- `decimal ScrapTolerancePercent` (Permissible loss variation)
- `int SequenceOrder` (Order of addition into process/reactor)
- `bool IsCriticalQC` (Requires strict `Released` QC status from inventory)
- `string? PhaseName` (e.g. "Reaction", "Separation", "Purification")
- `string? AdditionInstructions`

#### `ProcessFormulaCoProduct`
Represents co-products, by-products, or recyclable outputs generated by the formula.
- `int ProcessFormulaCoProductId` (PK)
- `int ProcessFormulaId` (FK -> `ProcessFormula`)
- `ProcessFormula? ProcessFormula`
- `int MaterialItemId` (FK -> `MaterialItem`)
- `MaterialItem? MaterialItem`
- `decimal AllocationPercent` (Yield percentage allocated to this item)
- `string Kind` ("CoProduct", "ByProduct", "RecycledSolvent", "Waste")
- `int? UomId` (FK -> `MaterialUOM`)
- `MaterialUOM? Uom`

### 2.2 Manufacturing Routing & Operations

#### `ProcessRoute` (Aggregate Root)
Defines the standard sequence of workstations and operations for chemical/process batches.
- `int ProcessRouteId` (PK)
- `string RouteCode` (e.g. "RT-POLY-LINE1", unique)
- `string Title`
- `int VersionNumber` (Default 1)
- `string Status` ("Draft", "Approved", "Retired")
- `int? PrimaryWorkCenterId` (FK -> `ProductionWorkCenter`)
- `ProductionWorkCenter? PrimaryWorkCenter`
- `decimal StandardCycleTimeHours`
- `string? Description`
- `bool IsActive` (Default true)
- `byte[]? RowVersion`
- Navigations:
  - `ICollection<ProcessRouteOperation> Operations`

#### `ProcessRouteOperation`
Individual step within a manufacturing route.
- `int ProcessRouteOperationId` (PK)
- `int ProcessRouteId` (FK -> `ProcessRoute`)
- `ProcessRoute? ProcessRoute`
- `int OperationSequence` (e.g. 10, 20, 30)
- `string OperationName` (e.g. "Blending", "Heating", "Reaction", "Centrifuge", "Packaging")
- `int ProductionWorkCenterId` (FK -> `ProductionWorkCenter`)
- `ProductionWorkCenter? ProductionWorkCenter`
- `decimal SetupTimeHours`
- `decimal RunTimeHoursPerBatch`
- `int? RequiredCrewSize`
- `int? CycleCountLimit` (Catalyst / equipment life limit before required maintenance; raises alert at threshold)
- `string? OperatingParametersJson` (Key-value set for temperature, pressure, agitation speed)

### 2.3 Master Planning (APP & MPS)

#### `ProductionPlan` (Aggregate Root)
Container for macro and master production plans.
- `int ProductionPlanId` (PK)
- `string PlanCode` (e.g. "APP-2027-MAIN", unique)
- `string Title`
- `string PlanType` ("APP", "MPS")
- `DateTime StartDate`
- `DateTime EndDate`
- `string Status` ("Draft", "UnderReview", "Approved", "Closed")
- `int? ActiveVersionId` (FK -> `PlanVersion`, published version)
- `PlanVersion? ActiveVersion`
- `byte[]? RowVersion`
- Navigations:
  - `ICollection<PlanVersion> Versions`

#### `PlanVersion` (Immutable Planning Snapshot - MPP)
The approved Master Production Plan version (output of APP).
- `int PlanVersionId` (PK)
- `int ProductionPlanId` (FK -> `ProductionPlan`)
- `ProductionPlan? ProductionPlan`
- `int VersionNumber` (e.g. 1, 2, 3)
- `string Status` ("Draft", "Published", "Superseded", "Frozen")
- `string PlanningHorizon` ("Monthly", "Weekly", "Daily")
- `DateTime HorizonStartDate`
- `DateTime HorizonEndDate`
- `string? ChangeSummary`
- `int? ApprovedById` (FK -> `Employee`)
- `DateTime? ApprovedDate`
- `byte[]? RowVersion`
- Navigations:
  - `ICollection<PlanItem> Items`
  - `ICollection<PlanningRecommendation> Recommendations`

#### `PlanItem`
Time-bucketed target for a product family or end item.
- `int PlanItemId` (PK)
- `int PlanVersionId` (FK -> `PlanVersion`)
- `PlanVersion? PlanVersion`
- `int MaterialItemId` (FK -> `MaterialItem`)
- `MaterialItem? MaterialItem`
- `DateTime PeriodStartDate`
- `DateTime PeriodEndDate`
- `decimal PlannedQuantity`
- `int? UomId` (FK -> `MaterialUOM`)
- `MaterialUOM? Uom`
- `decimal ForecastQuantity`
- `decimal CustomerOrderQuantity`
- `decimal NetRequiredQuantity`
- `bool IsFrozen` (Inside frozen zone; protected from automated re-planning)

### 2.4 MRP Recommendations & Genealogy

#### `PlanningRecommendation`
Actionable output of MRP calculations.
- `int PlanningRecommendationId` (PK)
- `int PlanVersionId` (FK -> `PlanVersion`)
- `PlanVersion? PlanVersion`
- `int MaterialItemId` (FK -> `MaterialItem`)
- `MaterialItem? MaterialItem`
- `string RecommendationType` ("Produce", "Purchase", "Transfer")
- `decimal RecommendedQuantity`
- `int? UomId` (FK -> `MaterialUOM`)
- `MaterialUOM? Uom`
- `DateTime RequiredDueDate`
- `DateTime SuggestedReleaseDate`
- `int? SuggestedWorkCenterId` (FK -> `ProductionWorkCenter`)
- `ProductionWorkCenter? SuggestedWorkCenter`
- `int? ProcessFormulaId` (FK -> `ProcessFormula`)
- `ProcessFormula? ProcessFormula`
- `string ActionStatus` ("Pending", "Approved", "Rejected", "Converted")
- `int? ConvertedProductionOrderId` (FK -> `ProductionOrder`, when approved)
- `ProductionOrder? ConvertedProductionOrder`

#### `ProductionBatchGenealogy`
Two-way batch tracing connecting raw material batch consumption to final product batches.
- `int ProductionBatchGenealogyId` (PK)
- `int OutputBatchId` (FK -> `ProductionBatch`, the produced parent batch)
- `ProductionBatch? OutputBatch`
- `int InputBatchId` (FK -> `ProductionBatch`, the raw/intermediate batch consumed)
- `ProductionBatch? InputBatch`
- `int ProductionRunId` (FK -> `ProductionRun`, the execution run)
- `ProductionRun? ProductionRun`
- `decimal ConsumedQuantity`
- `DateTime TransactionDate`
